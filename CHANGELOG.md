## [2.0.0] - 2026-10-01

### Added
- Electron desktop application for Windows (installer and portable builds).
- Live Wheatstone bridge calculations: Rx tolerance band, Rs range, ideal Rs.
- Question 3.4.8 decision table and verdict; worked answers for Questions 3.4.3 to 3.4.8.
- 9 V practical check with schematic; voltmeter sign near balance.
- MathJax LaTeX rendering; native Print / Save as PDF; Reset to PAT defaults; About dialog.
- GitHub repository with CI, automated releases, CodeQL and Dependabot.
